# Logs

이 디렉터리는 하네스 실행 중 남기는 검증 흔적과 관측 산출물을 위한 자리입니다.

예시:

- 테스트 실행 요약
- 실패 로그
- UI 스크린샷
- JSON 형태의 검증 결과

원칙:

- 원본이 너무 크면 요약과 핵심 증거만 남깁니다.
- 다음 실행이 문제를 재현하고 수정하는 데 도움이 되는 정보만 유지합니다.

권장 파일명 규칙:

- `YYYY-MM-DD-task-slug-summary.log`
- `YYYY-MM-DD-task-slug-screenshot.png`
- `YYYY-MM-DD-task-slug-result.json`
