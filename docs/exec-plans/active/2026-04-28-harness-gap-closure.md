# Harness Gap Closure

## 문제

현재 하네스는 핵심 축을 갖추고 있지만, 플랜 완료 처리, 훅 설치, 로그 규약, 진입 링크 같은 세부가 일부 빠져 있다.

## 제약 조건

- 현재 저장소는 아직 Git 저장소가 아니다.
- 훅과 Git 기반 명령은 없는 환경에서도 친절하게 실패해야 한다.
- 문서와 스크립트가 서로 연결되어야 한다.

## 제안하는 접근 방식

1. `AGENTS.md`와 `README.md`에 빠진 진입 링크를 보강한다.
2. 로그 가시성 문서를 추가한다.
3. 계획 완료 스크립트와 훅 설치 스크립트를 추가한다.
4. `.githooks/pre-commit` 기본 골격을 추가한다.

## 검증

- 새 문서가 루트 문서에서 찾아갈 수 있어야 한다.
- 새 스크립트가 사용법과 실패 메시지를 제공해야 한다.
- 훅 골격이 현재 스크립트와 일관되게 연결되어야 한다.
