# Reference-Informed Harness Hardening

## 문제

외부의 대표적인 하네스 엔지니어링 참고 저장소 둘을 바탕으로 현재 스캐폴드를 더 실전형 문서 체계로 보강한다.

## 제약 조건

- 현재 저장소는 코드 없는 하네스 스캐폴드 상태다.
- 참고 저장소의 아이디어는 가져오되 구조를 그대로 복제하지 않는다.
- 결과물은 Codex 중심 저장소 운영에 맞아야 한다.

## 제안하는 접근 방식

1. 외부 참고 저장소의 핵심 개념을 추출한다.
2. 현재 저장소의 루트 문서와 진입 문서를 보강한다.
3. 컨텍스트, 팀 패턴, 평가, 진화, 참고 자료 문서를 추가한다.
4. 반복 가능한 작업을 위해 템플릿을 추가한다.

## 검증

- 새 문서들이 기존 문서 구조와 자연스럽게 연결되는지 확인한다.
- 저장소가 `진입`, `실행`, `검증`, `진화` 흐름을 모두 설명하는지 확인한다.
- 문서가 Codex용 하네스라는 포지셔닝을 일관되게 유지하는지 확인한다.

## 의사결정 로그

- 2026-04-28: 외부 플러그인 구조를 그대로 복제하지 않고 문서 중심 Codex 하네스로 번역하기로 했다.
