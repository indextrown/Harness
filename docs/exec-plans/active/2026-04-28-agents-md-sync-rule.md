# AGENTS.md Sync Rule

## 문제

하네스 문서와 스크립트는 계속 늘어나는데, 진입 문서인 `AGENTS.md`가 같은 변경 안에서 항상 같이 갱신된다는 보장이 약하다.

## 제약 조건

- 규칙은 단순하고 분명해야 한다.
- 에이전트가 다음에도 쉽게 발견할 수 있어야 한다.
- 문서 구조와 진화 메커니즘 양쪽에 반영되어야 한다.

## 제안하는 접근 방식

1. `AGENTS.md` 핵심 규칙에 동기화 원칙을 추가한다.
2. 문서화 규칙에도 동일한 원칙을 명시한다.
3. `HARNESS_EVOLUTION.md`에 확인 질문으로 추가한다.
4. `README.md`에도 운영 원칙으로 반영한다.

## 검증

- `AGENTS.md`만 읽어도 동기화 규칙이 보이는지 확인한다.
- 하네스 진화 문서에서도 같은 원칙이 반복되는지 확인한다.
- 다음 하네스 업데이트 때 이 규칙을 자연스럽게 따를 수 있는지 확인한다.
