# Commandified Harness Workflow

## 문제

하네스 운영 문서를 실제 작업 명령으로 연결해 이슈, 계획, 워크트리, 검증, 병합 흐름을 표준화한다.

## 제약 조건

- 현재 저장소는 아직 Git 저장소가 아니다.
- GitHub CLI나 Git 의존 명령은 없는 환경에서 친절하게 실패해야 한다.
- 스크립트는 프로젝트 코드가 없는 현재 상태에서도 의미 있는 골격이어야 한다.

## 제안하는 접근 방식

1. 이슈 생성 스크립트를 추가한다.
2. 계획 생성 스크립트를 추가한다.
3. 워크트리 생성 스크립트를 추가한다.
4. 병합 스크립트를 추가한다.
5. 명령 사용법을 문서화한다.

## 검증

- 각 스크립트가 인자 부족 시 사용법을 출력하는지 확인한다.
- Git 또는 `gh`가 없을 때 친절한 오류를 내는지 확인한다.
- 문서가 스크립트 이름과 실제 파일 구조를 정확히 반영하는지 확인한다.
