# PR Command Workflow

## 문제

작업 브랜치를 원격에 올린 뒤 PR 생성 단계는 아직 사람 기억에 의존한다.

## 제약 조건

- GitHub CLI 로그인이 되어 있어야 한다.
- 작업 브랜치에서만 실행되어야 한다.
- 워킹트리가 깨끗하지 않으면 PR 생성이 흔들릴 수 있다.

## 제안하는 접근 방식

1. `gh pr create`를 감싼 스크립트를 추가한다.
2. PR 본문 템플릿을 저장소 안에 둔다.
3. `AGENTS.md`와 `docs/COMMANDS.md`에 연결한다.

## 검증

- 사용법이 출력되는지 확인한다.
- base 브랜치에서 실행하면 실패하는지 확인한다.
- 원격 push 전에는 실패하는지 확인한다.
