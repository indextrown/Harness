# Repository Bootstrap Recovery

## 문제

GitHub 레포가 삭제되거나 새 환경에서 다시 퍼블리시해야 할 때, 현재 절차는 사람 기억에 의존한다.

## 제약 조건

- 로컬 저장소가 아직 Git 초기화 전일 수 있다.
- GitHub 레포가 이미 있을 수도, 없을 수도 있다.
- 같은 명령으로 재실행 가능해야 한다.

## 제안하는 접근 방식

1. 로컬 Git 초기화부터 GitHub 퍼블리시까지 처리하는 스크립트를 추가한다.
2. 원격 레포가 이미 있으면 재생성하지 않고 푸시만 하도록 한다.
3. 관련 문서를 `AGENTS.md`, `README.md`, `docs/COMMANDS.md`에 연결한다.

## 검증

- 스크립트가 사용법을 출력하는지 확인한다.
- GitHub CLI 로그인 상태를 검사하는지 확인한다.
- 문서가 복구 시나리오를 설명하는지 확인한다.
