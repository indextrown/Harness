# YouTube-Informed Harness Refinements

## 문제

사용자가 제공한 하네스 엔지니어링 설명 영상의 실전 포인트를 현재 Codex용 하네스 저장소에 반영한다.

## 제약 조건

- 영상 내용은 특정 도구 예시를 포함하지만, 현재 저장소는 일반 Codex 스캐폴드다.
- 개념만 옮기지 말고 실제 운영 뼈대가 되는 문서와 스크립트도 같이 둔다.
- 아직 Git 저장소가 아니므로 워크트리 자동화는 골격 수준까지만 제공한다.

## 제안하는 접근 방식

1. 프롬프트, 컨텍스트, 하네스의 차이를 문서화한다.
2. 워크트리 우선 작업 흐름을 별도 문서로 정리한다.
3. 검증과 가드레일을 스크립트 중심으로 설명하는 문서를 추가한다.
4. 로그 디렉터리와 기본 검증 스크립트를 추가한다.

## 검증

- 새 문서가 기존 구조와 충돌하지 않는지 확인한다.
- `README.md`와 `AGENTS.md`에서 새 문서로 진입 가능한지 확인한다.
- `scripts/verify-task.sh`가 최소 구조를 점검하는지 확인한다.
