# Bootstrap Harness

## 문제

Codex 중심 작업을 위한 초기 하네스 우선 저장소 구조를 만든다.

## 제약 조건

- 빈 저장소에서 시작한다.
- 초기 스캐폴드는 작고 읽기 쉬워야 한다.
- 하나의 거대한 지시문 파일보다 지도형 에이전트 진입점을 선호한다.

## 제안하는 접근 방식

1. 짧은 `AGENTS.md`를 추가한다.
2. 구조화된 `docs/` 지식 베이스를 추가한다.
3. 실행 계획 폴더와 재사용 가능한 템플릿을 추가한다.
4. 하네스가 어떻게 확장될지 설명하는 루트 `README.md`를 추가한다.

## 검증

- 파일이 생성되었는지 확인한다.
- 문서들이 의도한 워크플로를 서로 참조하는지 확인한다.
- 구조가 쉽게 확장 가능한지 확인한다.
