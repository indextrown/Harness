# Plans

계획은 이 저장소에서 일급 아티팩트입니다.

## 계획을 작성해야 할 때

- 여러 단계로 이루어져 있거나, 위험이 있거나, 여러 파일에 걸치는 변경이라면 계획을 작성합니다.
- 작은 수정은 가볍게 유지합니다.
- 수용 기준이 불명확한 작업일수록 명시적인 계획을 선호합니다.

## 계획의 생명주기

- 초안은 `docs/exec-plans/active/`에 작성합니다.
- 작업이 진행되는 동안 계속 갱신합니다.
- 완료되면 `docs/exec-plans/completed/`로 옮깁니다.

## 좋은 계획이 포함해야 하는 것

- 문제 설명
- 제약 조건
- 제안하는 접근 방식
- 검증 전략
- 의사결정 로그
- 진행 체크리스트

기본 템플릿으로 `docs/exec-plans/templates/execution-plan-template.md`를 사용합니다.

## 함께 쓰면 좋은 템플릿

- 기능 또는 제품 명세: `docs/templates/spec-template.md`
- 역할별 작업 브리프: `docs/templates/task-brief-template.md`
- 검증 체크리스트: `docs/templates/verification-checklist-template.md`
