# Harness Factory Positioning

이 문서는 이 저장소가 하네스 생태계에서 어디에 위치하는지 설명합니다.

## 이 저장소는 무엇인가

이 저장소는 `Codex 작업용 하네스 스캐폴드`입니다.

즉, 특정 앱 자체가 아니라 앱을 만들고 유지보수하는 에이전트 작업 환경을 정의하는 저장소입니다.

## 이 저장소는 무엇이 아닌가

- 특정 런타임에 종속된 플러그인만을 목표로 하지 않습니다.
- 거대한 단일 지시문 저장소를 지향하지 않습니다.
- 완전 자율 멀티에이전트 시스템을 전제로 하지 않습니다.

## 참조 관점과의 관계

- `awesome-harness-engineering`와의 관계:
  이 저장소는 분류 체계를 참고해 필요한 운영 축을 빠짐없이 문서화합니다.
- `revfactory/harness`와의 관계:
  이 저장소는 팀 아키텍처 팩토리 관점을 참고하되, Codex 저장소용 운영 문서와 템플릿으로 변환합니다.

## 저장소가 성장하면 추가할 것

- 실제 검증 스크립트
- 프로젝트별 아키텍처 규칙 검사
- 작업 브리프 자동 생성기
- 회귀 평가 하네스
- 반복 피드백을 코드화하는 린터 또는 체크 도구
